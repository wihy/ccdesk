**Goal:** 把 ccdesk 从 P1 的 observe-only 推进到 P2：闸门真正接入 CC，对 AskUserQuestion 做带护栏的自动/人工代答，并把 `decision` 写进账本，从而解除 P1 的三条已知限制。

**Architecture:** 闸门（`PreToolUse` hook，matcher 精确匹配 `AskUserQuestion`）把请求 POST 给常驻 daemon 的 `/decide`；daemon 按「护栏 → 缓存 → 判官 → 人工窗口」四层出决定，把决定 append 进 `ledger.jsonl`，并把答案通过 `updatedInput` 回传给闸门注入会话。判官（LLM）在本机无可用通道时按 spec §9 自动降级，不阻断链路。

**Tech Stack:** Python 3.13（stdlib only，无第三方依赖）、pytest、Swift 6 / SwiftUI（菜单栏 App）、launchd。

**Spec:** `docs/superpowers/specs/2026-08-14-ccdesk-design.md`（P2 内容见 §五 三态决策引擎、§八 可追踪、§十一 分期验收）

## Global Constraints

- **闸门三条铁律不可破**：永不返回 `deny`；永不非零退出；永不打印 traceback。任何异常路径一律自降级为 `ask`。
- **闸门自降级线 7.5s**（`config.GATE_DEADLINE_S`），由闸门内部 watchdog 保证，绝不依赖 CC 侧 timeout 兜底（U2 已坐实 CC 超时后是 fall through 而非必然拒绝）。
- **单向写**：只有 daemon 写 `~/.ccdesk/`；闸门与 App 一律走 HTTP。
- **零第三方依赖**：Python 侧只用 stdlib（现有代码即如此，不得引入 requests/pydantic 等）。
- **判官不可用是常态而非故障**：本机实测 `claude -p --model haiku` 单次 42.5s / 42.8s（两次，含空 settings + 禁 MCP），远超 7.5s 期限；且无 `ANTHROPIC_API_KEY`、无 `apiKeyHelper`。因此判官层必须在无凭证时静默降级为「护栏 + 缓存命中才自动，其余 ask」，并在 `decided_by` 如实标注 `judge_unavailable`。
- **U5 四条未测边界必须做成硬护栏**（详见 Task 3）：只对单问题 + 单选自动答；注入 label 必须严格属于该问题的 `options[].label`；`multiSelect:true` / 多问题 / 无 options 一律 `ask`；CC 版本变更需自检降级。
- **测试口径**：Python 用 `/opt/homebrew/Caskroom/miniconda/base/bin/python3 -m pytest`；Swift 用 `cd app/CCDesk && swift test`。任何任务收尾时两套都必须绿。

```python
"""决策写入侧。把 /decide 的结论落成账本行，口径必须与 collector 完全一致。"""
from __future__ import annotations

from datetime import datetime, timezone

from .ledger import Ledger, input_fingerprint, make_req_id


def _now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


def build_req_id(payload: dict) -> str:
    """从 PreToolUse hook payload 现算 req_id。

    口径必须与 collector.py 走 events.py 的那条完全一致：同样把 tool_name
    传给 input_fingerprint，让 VOLATILE_INPUT_KEYS 按工具剔除结局侧才出现的键。
    只改一侧等于没改（C-3 教训）。
    """
    tool_name = str(payload.get("tool_name") or "")
    tool_input = payload.get("tool_input")
    if not isinstance(tool_input, dict):
        tool_input = {"_raw": str(tool_input)}
    return make_req_id(
        str(payload.get("session_id") or ""),
        str(payload.get("prompt_id") or ""),
        tool_name,
        input_fingerprint(tool_input, tool_name),
    )


def current_allow_count(merged: dict, req_id: str) -> int:
    record = merged.get(req_id) or {}
    try:
        return int(record.get("allow_count") or 0)
    except (TypeError, ValueError):
        return 0


def record_decision(ledger: Ledger, req_id: str, decision: str, decided_by: str,
                    confidence: float | None, latency_ms: int,
                    allow_count_before: int) -> dict:
    """append 一条决策行。allow_count 只在 allow 时递增——duplicate_allow 对账依赖它。"""
    row = {
        "req_id": req_id,
        "decision": decision,
        "decided_by": decided_by,
        "latency_ms": int(latency_ms),
        "ts_decision": _now_iso(),
        "allow_count": allow_count_before + (1 if decision == "allow" else 0),
    }
    if confidence is not None:
        row["confidence"] = float(confidence)
    ledger.append(row)
    return row
```

- [ ] **Step 4: 实现 `ccdesk/judge.py`**

```python
"""AskUserQuestion 决策层：护栏 → 缓存 → 判官 → 降级。

设计前提（全部实测，勿凭想象改）：
* U5 已坐实闸门可用 `allow` + `updatedInput` 代答，会话不弹窗直接消费答案。
* 但 U5 只测过「单问题 + 单选 + 合法 label」，其余形态一律未验证——
  未验证的形态在这里全部走 ask，不赌。
* 本机 `claude -p --model haiku` 实测 42.5s，远超 7.5s 闸门期限；且无
  ANTHROPIC_API_KEY。所以 `_llm_available()` 现实中恒 False，走 spec §9
  的降级路径。判官代码保留，等有可用通道时自动生效。
"""
from __future__ import annotations

import json
import os
from dataclasses import dataclass

from . import config


@dataclass
class Verdict:
    decision: str                      # 只允许 allow / ask —— 永不 deny
    decided_by: str
    confidence: float | None = None
    updated_input: dict | None = None


def guardrail_check(tool_input: dict) -> str | None:
    """U5 未测边界的硬护栏。返回拒绝原因；None 表示可以继续往下判。"""
    if not isinstance(tool_input, dict):
        return "no_questions"
    questions = tool_input.get("questions")
    if not isinstance(questions, list) or not questions:
        return "no_questions"
    if len(questions) > 1:
        return "multi_question"
    q = questions[0]
    if not isinstance(q, dict):
        return "no_questions"
    if q.get("multiSelect"):
        return "multiselect"
    options = q.get("options")
    if not isinstance(options, list) or not options:
        return "no_options"
    if not any(isinstance(o, dict) and o.get("label") for o in options):
        return "no_options"
    return None


def validate_answer(question: dict, answer) -> bool:
    """注入值必须严格等于某个 option.label。防的是「判官编了个选项」。"""
    if not isinstance(answer, str) or not answer:
        return False
    options = question.get("options")
    if not isinstance(options, list):
        return False
    return any(isinstance(o, dict) and o.get("label") == answer for o in options)


def build_updated_input(tool_input: dict, answer: str) -> dict:
    """answers 的形状由 U5 从真实 PostToolUse 样本坐实：{问题原文: option.label}。"""
    question = tool_input["questions"][0]
    return {
        "questions": tool_input["questions"],
        "answers": {question.get("question"): answer},
    }


def cache_key(payload: dict) -> str:
    from .ledger import input_fingerprint
    tool_name = str(payload.get("tool_name") or "")
    tool_input = payload.get("tool_input")
    if not isinstance(tool_input, dict):
        tool_input = {}
    return f"{tool_name}:{input_fingerprint(tool_input, tool_name)}"


def _llm_available() -> bool:
    """判官通道是否可用。

    实测结论（2026-08-19）：`claude -p` 单次 42.5s，不可能塞进 7.5s 期限；
    本机也没有 ANTHROPIC_API_KEY。所以只认 API key 这一条通道。
    """
    return bool(os.environ.get("ANTHROPIC_API_KEY"))


def _call_llm_judge(question: dict, budget_s: float) -> tuple[str, float] | None:
    """向 haiku 问「该选哪个」。返回 (label, confidence)，任何异常一律 None。

    有意用 stdlib urllib：全项目零第三方依赖。
    """
    import urllib.error
    import urllib.request

    labels = [o.get("label") for o in question.get("options", [])
              if isinstance(o, dict) and o.get("label")]
    prompt = (
        "你在替用户回答一个选择题。只能从给定选项里选一个，"
        "并给出 0~1 的置信度。只输出 JSON：{\"answer\":\"<选项原文>\",\"confidence\":<数字>}\n\n"
        f"问题：{question.get('question')}\n"
        f"选项：{json.dumps(labels, ensure_ascii=False)}\n"
        + "\n".join(
            f"- {o.get('label')}：{o.get('description', '')}"
            for o in question.get("options", []) if isinstance(o, dict)
        )
    )
    body = json.dumps({
        "model": config.JUDGE_MODEL,
        "max_tokens": 128,
        "messages": [{"role": "user", "content": prompt}],
    }).encode("utf-8")
    request = urllib.request.Request(
        "https://api.anthropic.com/v1/messages", data=body,
        headers={
            "content-type": "application/json",
            "anthropic-version": "2023-06-01",
            "x-api-key": os.environ.get("ANTHROPIC_API_KEY", ""),
        })
    try:
        with urllib.request.urlopen(request, timeout=budget_s) as response:
            data = json.loads(response.read().decode("utf-8"))
        text = "".join(block.get("text", "") for block in data.get("content", []))
        parsed = json.loads(text[text.index("{"):text.rindex("}") + 1])
        return str(parsed["answer"]), float(parsed["confidence"])
    except Exception:              # noqa: BLE001 — 判官失败不是故障，是降级信号
        return None


def decide(payload: dict, cache: dict) -> Verdict:
    """主入口。任何一步不确定都落 ask —— 「永不在不确定时 allow」。"""
    tool_input = payload.get("tool_input")
    if not isinstance(tool_input, dict):
        tool_input = {}

    reason = guardrail_check(tool_input)
    if reason is not None:
        return Verdict("ask", f"guardrail:{reason}")

    question = tool_input["questions"][0]

    key = cache_key(payload)
    cached = cache.get(key)
    if cached is not None:
        answer, confidence = cached
        if validate_answer(question, answer):
            return Verdict("allow", "cache", confidence,
                           build_updated_input(tool_input, answer))

    if not _llm_available():
        return Verdict("ask", "judge_unavailable")

    result = _call_llm_judge(question, config.JUDGE_BUDGET_S)
    if result is None:
        return Verdict("ask", "judge_error")
    answer, confidence = result
    if not validate_answer(question, answer):
        return Verdict("ask", "guardrail:illegal_label", confidence)
    if confidence < config.JUDGE_MIN_CONFIDENCE:
        return Verdict("ask", "judge:low_confidence", confidence)
    cache[key] = (answer, confidence)
    return Verdict("allow", "judge:haiku", confidence,
                   build_updated_input(tool_input, answer))
```

```python
def emit(decision: str, reason: str, updated_input: dict | None = None) -> None:
    output = {
        "hookEventName": "PreToolUse",
        "permissionDecision": decision,
        "permissionDecisionReason": reason,
    }
    if updated_input is not None:
        # U5 坐实：allow 不带 updatedInput 会被 CC 直接丢弃
        # （if(!updatedInput && requiresUserInteraction()) return null）。
        output["updatedInput"] = updated_input
    sys.stdout.write(json.dumps({"hookSpecificOutput": output}, ensure_ascii=False) + "\n")
    sys.stdout.flush()


def normalize(decision: str, reason: str,
              updated_input: dict | None) -> tuple[str, str, dict | None]:
    """allow 必须带 updatedInput，否则 CC 会丢弃它、工具悬着不动。
    与其把决定交给 CC 丢弃，不如自己降级成 ask —— 行为可预期，且仍不违反永不 deny。"""
    if decision == "allow" and not updated_input:
        return "ask", f"ccdesk: allow 缺 updatedInput，降级 ask（原因 {reason}）", None
    return decision, reason, updated_input
```

`_request()` 改为返回三元组（多带回 `body.get("updatedInput")`，非 dict 则 None）；`ask_daemon()` 的降级返回同步改成三元组；`main()` 末尾改为 `emit(*normalize(decision, reason, updated_input))`。

```python
"""把闸门装进 / 卸出 ~/.claude/settings.json。

纪律：
* 幂等——装两次不会出现两条。
* 非破坏——先备份，解析失败一律拒绝写（用户的 settings.json 丢不起）。
* 卸载只删自己那条，绝不动别人的 hook。
* matcher 精确匹配 AskUserQuestion：本机 defaultMode=auto + Bash(*) 下它是唯一会
  产生 PermissionRequest 的工具（实测 events.jsonl 尾部 2000 行 PostToolUse 422 /
  PermissionRequest 0），挂全量只会给每次工具调用白加一次 HTTP 往返。
"""
from __future__ import annotations

import json
import shutil
import sys
import time
from pathlib import Path

MATCHER = "AskUserQuestion"
GATE_PATH = str(Path(__file__).resolve().parent.parent / "hooks" / "ccdesk_gate.py")
SETTINGS_PATH = Path.home() / ".claude" / "settings.json"


def hook_entry() -> dict:
    return {
        "matcher": MATCHER,
        "hooks": [{
            "type": "command",
            "command": sys.executable,
            "args": [GATE_PATH],
            # CC 侧 timeout 只作最外层保险；真正的自降级由闸门内部 7.5s watchdog 保证。
            "timeout": 10,
        }],
    }


def _is_ours(entry: dict) -> bool:
    for hook in entry.get("hooks", []) or []:
        for arg in hook.get("args", []) or []:
            if str(arg).endswith("ccdesk_gate.py"):
                return True
    return False


def _load(settings_path: Path) -> dict:
    try:
        raw = settings_path.read_text(encoding="utf-8")
    except OSError:
        return {}
    if not raw.strip():
        return {}
    try:
        data = json.loads(raw)
    except ValueError as exc:
        raise ValueError(f"{settings_path} 不是合法 JSON，拒绝写入：{exc}") from exc
    if not isinstance(data, dict):
        raise ValueError(f"{settings_path} 顶层不是对象，拒绝写入")
    return data


def _save(settings_path: Path, data: dict) -> None:
    if settings_path.exists():
        stamp = time.strftime("%Y%m%d-%H%M%S")
        shutil.copy2(settings_path, settings_path.with_suffix(f".json.ccdesk-bak.{stamp}"))
    settings_path.parent.mkdir(parents=True, exist_ok=True)
    tmp = settings_path.with_suffix(".json.ccdesk-tmp")
    tmp.write_text(json.dumps(data, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    tmp.replace(settings_path)


def install(settings_path: Path = SETTINGS_PATH) -> str:
    data = _load(settings_path)
    hooks = data.setdefault("hooks", {})
    entries = hooks.setdefault("PreToolUse", [])
    if any(_is_ours(e) for e in entries if isinstance(e, dict)):
        return "already"
    entries.append(hook_entry())
    _save(settings_path, data)
    return "installed"


def uninstall(settings_path: Path = SETTINGS_PATH) -> str:
    data = _load(settings_path)
    entries = (data.get("hooks") or {}).get("PreToolUse")
    if not isinstance(entries, list):
        return "absent"
    kept = [e for e in entries if not (isinstance(e, dict) and _is_ours(e))]
    if len(kept) == len(entries):
        return "absent"
    data["hooks"]["PreToolUse"] = kept
    _save(settings_path, data)
    return "removed"


def status(settings_path: Path = SETTINGS_PATH) -> dict:
    try:
        data = _load(settings_path)
    except ValueError:
        return {"installed": False, "matcher": None}
    for entry in (data.get("hooks") or {}).get("PreToolUse") or []:
        if isinstance(entry, dict) and _is_ours(entry):
            return {"installed": True, "matcher": entry.get("matcher")}
    return {"installed": False, "matcher": None}
```

```python
"""拿历史请求重放当前规则集，看规则改动会改变哪些决定。

只读——不写账本、不碰会话。重放用**空缓存**，避免历史缓存把结果染成 allow。
"""
from __future__ import annotations

from datetime import datetime

from . import judge


def _parse(ts: str) -> datetime | None:
    try:
        return datetime.fromisoformat(str(ts))
    except (TypeError, ValueError):
        return None


def replay(merged: dict, since_s: float, now_iso: str) -> list[dict]:
    now = _parse(now_iso)
    rows: list[dict] = []
    for req_id, record in merged.items():
        tool_input = record.get("tool_input")
        if not isinstance(tool_input, dict):
            continue                       # P1 老记录没存 tool_input，重放不了
        ts = _parse(record.get("ts_request"))
        if now is not None and ts is not None and (now - ts).total_seconds() > since_s:
            continue
        verdict = judge.decide(
            {"session_id": record.get("session_id", ""),
             "prompt_id": record.get("prompt_id", ""),
             "tool_name": record.get("tool_name", ""),
             "tool_input": tool_input},
            {})                            # 空缓存：重放看的是规则，不是历史缓存
        was = record.get("decision")
        rows.append({"req_id": req_id, "tool_name": record.get("tool_name"),
                     "was": was, "now": verdict.decision,
                     "changed": was is not None and was != verdict.decision})
    return rows
```

## 实施中的偏差（与原计划不一致的地方，如实记下）

**1. `normalize()` 的降级条件比原计划窄。**
原计划写「allow 缺 `updatedInput` 一律降级 ask」。实施时发现这会**破坏普通工具的放行**——
`requiresUserInteraction()` 只对 AskUserQuestion 这类工具为 true，Bash 等普通工具的 allow
本来就不需要 `updatedInput`。现按 `_NEEDS_UPDATED_INPUT` 白名单按工具名区分。
是既有测试 `test_allow_from_daemon_is_passed_through`（用 `tool_name=Bash`）把这个 bug 挡下来的。

**2. 多了一项计划外改动：闸门落账补 `tool_input` / `input_digest`。**
Task 6 做完后跑真实 `ccdesk replay`，输出是「重放 0 条」——因为 collector 那侧只存
`input_digest` 摘要，重放不了，replay 等于摆设。修法是让闸门在落账时补上完整
`tool_input`（只有真正过闸门的请求才存，量很小）。这条不在原计划里，是端到端验证暴露的。

**3. Task 8 的实测纠正了一处长期记错的口径。**
真实权限弹窗的 `waitingFor` 是 **`permission prompt`**，不是 spec 与 README 里写的
`dialog open`。生产代码只透传该字段、不按值分支，功能未受影响，已回写 spec 四处。

**4. 复验时抓到「部署与仓库不一致」。**
